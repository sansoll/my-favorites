# 내가 좋아하는 것들

좋아하는 것에 쓴 돈을 기록하고, 응원법을 모아서 외우는 개인용 앱입니다.

- 삼성 갤럭시와 크롬 기준의 PWA
- 혼자 쓰는 앱이며 스토어에는 올리지 않음
- 로그인과 서버 없이 모든 데이터를 폰에만 저장
- 설치 후 오프라인으로 작동

> 현재 상태: 명세 정리 단계이며 앱 코드는 아직 없습니다.

## 범위

**이번 개발에 포함:** 지출 기록, 내역, 통계, 응원법, 연말 결산, 설정, 백업

**이번 개발에서 제외:** 위젯, 카드 내역 대조, 결제 내역 자동 가져오기, 가사 크롤링, 아이폰 지원

## 화면 구성

하단 탭은 `기록`, `내역`, `통계`, `응원법`, `설정`이고, 연말 결산은 `통계` 안에 둡니다.

## 기본 데이터

**대상:** 아이유, 문별, 마마무, 다비치, 에스파, 윤하, 잠뜰, 기타

| 분류 | 세부 버튼 |
|---|---|
| 행사 | 콘서트, 팬콘서트, 팬미팅, 팬싸인회, 팝업, 콜라보행사, 생일카페 |
| 체험 | 원데이 클래스, DIY |
| 경비 | 교통, 숙박 |
| 상품 | 앨범, 굿즈, 콘서트 굿즈, 앨범 굿즈, 생일 굿즈, 비공굿, 포토카드, 만화책 |
| 멤버십 | 팬클럽, 유튜브 멤버십 |
| 기타 | 없음 |

- 대상, 분류, 세부 버튼은 모두 추가, 이름 수정, 삭제가 가능합니다.
- 대상, 분류, 세부 버튼 목록의 끝에 `+` 버튼을 두어 기록 중에 바로 추가합니다. 추가한 항목은 바로 선택됩니다.
- 앞뒤 공백을 제외하고 같은 이름은 새로 만들지 않고 기존 항목을 선택합니다.
- 대상 `기타`는 항상 있으며 삭제할 수 없습니다.
- 분류와 세부 버튼은 한 번에 전체 삭제할 수 있고, `기본 예시 다시 넣기`로 복구할 수 있습니다.
- 공방, DIY, 만화책 같은 취미 지출은 대상 `기타`로 기록합니다.

### 분류 기준

- 입장이나 참가에 낸 돈은 행사 또는 체험, 물건은 상품입니다.
- 팬클럽 키트는 예외로 멤버십의 `팬클럽`에 넣습니다.
- 교통비와 숙박비는 행사에 넣지 않고 경비로 기록합니다.
- 식비는 기록하지 않습니다.

## 지출 기록

`대상` → `분류` → `세부 버튼(건너뛰기 가능)` → `금액` → 저장

- 금액은 원 단위 정수입니다.
- 날짜는 오늘로 자동 입력되고 과거와 미래로 바꿀 수 있습니다. 돈이 나간 날을 기준으로 합니다.
- 할부는 결제일에 전액을 기록합니다.
- 메모는 평소에 접어 두며 입력은 선택입니다.
- 분류가 하나도 없으면 `대상` → `금액`으로 기록합니다.
- 세부 버튼이 없는 분류는 바로 금액으로 넘어갑니다.

## 내역, 환불, 삭제

- 기록은 최신순으로 표시하고 대상별로 걸러 봅니다.
- 기록을 눌러 날짜, 대상, 분류, 세부, 금액, 메모, 환불 금액을 수정합니다.
- 환불 금액의 기본값은 0원이고 결제 금액보다 클 수 없습니다. 양도로 돌려받은 돈도 같은 칸에 입력합니다.
- 집계 금액은 `결제 금액 - 환불 금액`이며 결제한 달에 반영합니다.
- 전액 환불한 기록도 내역에 남습니다.
- 기록을 삭제한 직후에는 되돌릴 수 있습니다.
- 미래 날짜 기록은 `예정`으로 표시하고 해당 달의 지출과 결산에 포함합니다.

## 통계

모든 금액은 집계 금액 기준입니다.

- 월별 1위 대상과 1위 분류
- 대상 랭킹
- 분류 랭킹
- 대상별 분류 금액과 세부 금액
- 연간 대상별 금액
- 세부 합계: 세부 버튼을 누른 기록만 합산하며, 건너뛴 기록은 대상 상세에서 `세부 없음`으로 표시

## 응원법

- 대상별, 곡별로 저장하고 곡 제목으로 검색합니다.
- 곡 하나는 대상 하나에만 저장합니다.
- 곡마다 원본 가사 하나와 응원법 층 하나를 따로 저장합니다.
- 가사는 붙여넣기로 입력합니다. 앱에 가사를 미리 넣거나 크롤링하지 않습니다.
- 공유 메뉴로 가사를 넣는 기능은 지원 여부를 확인한 뒤 추가합니다.
- 원본은 잠가 두고 `가사 수정`에서만 고칩니다. 고친 부분의 응원법은 다시 표시해야 할 수 있습니다.
- 응원법을 초기화해도 원본은 유지합니다.
- **떼창:** 원본 가사의 일부를 선택해 색을 지정합니다.
- **추가 응원:** 가사에 없는 구호를 원하는 위치에 넣고 색을 지정합니다.
- 곡마다 링크를 여러 개 저장합니다.
- 공연장 보기는 큰 글자와 어두운 화면을 제공하고, 지원되는 브라우저에서는 보는 동안 화면이 꺼지지 않게 합니다.

| 보기 모드 | 떼창 | 추가 응원 |
|---|---|---|
| 응원법 보기 | 색으로 강조 | 색으로 강조해서 표시 |
| 원본 가사 | 일반 가사 | 숨김 |
| 외우기 | 칸으로 가림 | 칸으로 가림 |

- 외우기 모드에서 칸을 누르면 그 부분만 보여 줍니다.
- 마지막에 쓴 보기 모드를 기억합니다.
- 곡 상세를 열면 펼친 횟수를 1회 세고, 같은 곡을 30분 안에 다시 열면 세지 않습니다.

## 연말 결산 카드

넘겨 보는 카드 6장이며 이미지로 저장할 수 있습니다.

1. 올해 총액
2. 돈을 많이 쓴 달 TOP 3
3. 많이 쓴 대상 TOP 3
4. 많이 쓴 분류 TOP 3
5. 응원법을 많이 펼친 달 TOP 3
6. 많이 펼친 곡 TOP 3

- 언제든 볼 수 있고 연도를 바꿔 지난 결산도 볼 수 있습니다.
- 연도 기준은 1월 1일부터 12월 31일까지이며 폰의 시간을 따릅니다.
- 3개가 안 되면 있는 만큼만 표시하고, 공동 순위는 같은 순위로 표시합니다.
- 데이터가 없는 카드는 건너뜁니다.

## 데이터 변경 규칙

- 대상이나 분류 이름을 바꾸면 지난 기록에도 반영합니다.
- 기록이 있는 대상을 삭제하면 버튼만 숨기고, 기록과 곡은 원래 이름으로 남깁니다.
- 기록이 있는 분류를 삭제하면 금액은 집계에 남기고 `미분류`로 표시합니다.

## 저장과 백업

- 지출, 목록, 가사, 응원법, 펼친 기록을 파일 하나로 내보내고 불러옵니다.
- 불러올 때는 덮어쓰기 전에 확인을 받습니다.
- 앱이나 브라우저 데이터를 지웠을 때 백업이 없으면 복구할 수 없습니다.
- 지출 기록과 가사는 이 저장소에 올리지 않습니다.

## 제작 순서

1. 위젯 없는 PWA를 만들고 폰 화면 크기로 테스트합니다.
2. GitHub Pages에 올려 크롬으로 설치하고, 실제 갤럭시에서 확인하며 고칩니다.
3. 나중에 같은 화면을 안드로이드 앱으로 감싸고 위젯을 붙입니다. 이 단계에는 Android Studio가 필요합니다.

위젯 확장을 위해 저장 부분을 분리하고 기록 저장 로직을 하나로 묶습니다. 위젯의 입력 순서는 앱과 같고, 대상과 분류 관리는 앱에서 합니다.
