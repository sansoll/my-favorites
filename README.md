# 내가 좋아하는 것들

좋아하는 것에 쓴 돈을 기록하고, 응원법을 모아 외우는 앱입니다.

- 삼성 갤럭시 + 크롬 기준 PWA, 오프라인 작동
- 로그인·서버 없이 모든 데이터를 폰에만 저장
- 특정 가수나 팬덤을 가정하지 않고, 실제 이름을 미리 넣지 않음
- Play 스토어에는 올리지 않음

> 현재 명세 단계이며 앱 코드는 아직 없습니다. 화면 흐름은 [STORYBOARD.md](STORYBOARD.md)를 보세요.

## 범위

- **1단계:** 튜토리얼, 지출 기록, 정기 결제, 내역, 통계, 다녀온 곳, 연말 결산, 응원법, 테마, 설정, 내보내기·불러오기
- **나중에:** 위젯, 구글 드라이브 백업 (2단계 안드로이드 앱)
- **안 함:** 카드·결제 내역 자동 가져오기, 가사 크롤링, 앱 안 지도, 아이폰

하단 탭: `기록` `내역` `통계` `응원법` `설정` (연말 결산은 통계 안)

## 튜토리얼

- 첫 실행 때만 실제 화면 위에서 누를 곳을 강조하며 안내합니다. 강조된 곳을 눌러도 다음으로 넘어갑니다.
- `이전` `다음` `건너뛰기`가 있고, 마지막 단계는 `시작하기`입니다. 설정에서 다시 볼 수 있습니다.
- 사용법만 알려 주고 기록 기준은 제시하지 않습니다. 예시는 저장하지 않습니다.

## 목록 구조

`대상` → `분류` → `세부` 세 단계이며, 나누는 방법은 사용자가 정합니다. 처음에는 모두 `기타`만 있고 `기타`는 지울 수 없습니다.

- 분류와 세부는 대상마다 따로입니다. 통계에서만 공백을 뺀 이름이 같으면 합쳐서 셉니다.
- 추가, 이름 바꾸기, 순서 바꾸기, 삭제는 모두 기록 화면에서 합니다. `편집`(또는 길게 누르기) → `≡`로 순서, `⋮`로 이름 바꾸기·데이터만 삭제·삭제.
- 각 항목 옆에 이번 달 금액을 보여 줍니다.

### 프리셋

설정에서 분류·세부 묶음을 만들어 두고, 새 대상을 만들 때 고르면 복사해 넣습니다.

프리셋을 고치면 적용 범위를 고릅니다: **프리셋에만 / 대상 전체 / 대상 골라서**. 대상에 추가할 때 같은 이름이 있으면 건너뛰고, 뺄 때는 삭제와 같이 기록을 `기타`로 옮깁니다.

## 지출 기록

`대상` → `분류` → `세부` → `금액` → 저장 → 첫 화면으로 돌아가 "저장했어요" 알림

- 세부를 건너뛰면 `기타`로 저장합니다. `기타`에는 선택 입력인 내용 칸이 있습니다.
- 날짜는 오늘이 기본이고 바꿀 수 있습니다. 미래 날짜는 `예정`으로 표시합니다.
- 메모는 접어 두며 선택입니다.
- **장소**(선택): 이름만 적습니다(예: `KSPO DOME`). 전에 쓴 장소는 눌러서 다시 고릅니다. 기록 상세에서 장소를 누르면 지도 앱에서 열립니다.

## 정기 결제

- 금액 화면의 `매달 반복` 또는 설정의 `정기 결제`에서 등록합니다. 대상·분류·세부·금액·결제일을 가집니다.
- 결제일에 기록을 자동으로 만들고, 그 전까지는 `예정`입니다. 없는 날짜(31일 등)는 그 달 마지막 날로 처리합니다.
- 알림은 기본 전날 오후 8시이며 바꿀 수 있습니다. 기록 탭 위에도 다가오는 결제를 보여 줍니다.
- 결제마다 켜고 끌 수 있고, 눌러서 수정·삭제합니다.
- PWA는 닫혀 있을 때 정확한 시간의 폰 알림이 보장되지 않습니다. 확실한 알림은 2단계 안드로이드 앱에서 지원합니다.

## 내역

- 최신순으로 보고, 대상과 기간으로 거릅니다.
- 기록을 누르면 **보기 전용**으로 열립니다. `수정`을 눌러야 고칠 수 있고, 수정 중에만 `삭제`가 보입니다.
- 여러 건을 골라 한 번에 옮기거나 지울 수 있고, 지운 뒤 잠깐 `되돌리기`가 나옵니다.
- **환불:** 돌려받은 금액을 입력합니다(결제 금액 이하). 집계는 `결제 - 환불`이고, 전액 환불한 기록도 남습니다.

## 삭제

기록 외의 삭제는 지워지거나 옮겨지는 범위와 건수를 보여 주고 확인을 받습니다.

| 삭제 | 결과 |
|---|---|
| 대상 | 분류, 세부, 지출 기록, 응원법 모두 삭제 |
| 분류 | 기록은 그 대상의 `기타 › 기타`로 이동 |
| 세부 | 기록은 같은 분류의 `기타`로 이동 |
| 데이터만 삭제 | 항목은 남기고 지출 기록만 삭제 (대상의 응원법은 유지) |

`기타`로 옮긴 기록의 내용 칸에는 이전 이름(`행사 > 콘서트` 등)을 자동으로 넣습니다.

## 통계

- `월`/`연`을 고르고 이전 기간으로 넘겨 봅니다. 기본은 이번 달입니다.
- 총액, 1위 대상·분류, 대상·분류·세부 랭킹을 보여 줍니다.

## 다녀온 곳

통계에서 들어갑니다. 장소를 남긴 기록을 장소별로 모아 봅니다.

- `올해` / `전체`, `많이 간 순` / `최근 순` / `많이 쓴 순`으로 봅니다.
- 장소마다 다녀온 횟수, 쓴 돈, 함께한 대상을 보여 주고, 펼치면 날짜별 기록이 나옵니다.
- 같은 날 같은 장소에 남긴 기록(티켓, 교통, 숙박 등)은 한 번 다녀온 걸로 셉니다.
- `지도 앱에서 열기`, `이름 바꾸기`를 할 수 있습니다. 이미 있는 이름으로 바꾸면 하나로 합칩니다.

## 연말 결산

카드 7장: 올해 총액 / 많이 쓴 달 TOP 3 / 대상 TOP 3 / 분류 TOP 3 / 가장 많이 간 곳 TOP 3 / 응원법 많이 펼친 달 TOP 3 / 많이 펼친 곡 TOP 3

- 새해 첫 실행 때 지난해 결산을 한 번 자동으로 보여 줍니다. 처음 열 때만 축하 효과가 나옵니다.
- 카드는 밀어서 넘기고, 통계에서 언제든 연도를 골라 다시 봅니다. 이미지로 공유·저장할 수 있습니다.
- 데이터가 없는 카드는 건너뛰고, 3개가 안 되면 있는 만큼만 보여 줍니다.

## 응원법

- 대상별·곡별로 저장하고 제목으로 검색합니다. 가사는 붙여넣기로만 넣습니다.
- 곡마다 **원본 가사**와 **응원법 층**을 따로 저장합니다. 응원법을 초기화해도 원본은 남습니다.
- `편집` 모드에서 합니다.
  - **떼창 색칠:** 단어를 눌러 색을 칠합니다(기본 4색).
  - **추가 응원:** 단어를 누르고 `단어 앞` / `단어 뒤` / `줄 아래` 중 위치를 골라 넣습니다.
  - 가사 수정, 초기화, 곡 삭제도 편집 모드 안에 있습니다.
- 곡마다 링크를 여러 개 저장합니다.

| 보기 | 떼창 | 추가 응원 |
|---|---|---|
| 응원법 | 색으로 강조 | 표시 |
| 원본 | 일반 가사 | 숨김 |
| 외우기 | 칸으로 가림 (눌러서 열기) | 칸으로 가림 |

- **공연장 모드:** 큰 글자, 어두운 화면, 화면 꺼짐 방지. `응원법` 보기에서만 켤 수 있습니다.
- 곡을 열면 펼친 횟수를 셉니다(같은 곡은 30분 안에 다시 세지 않음).

## 테마와 꾸미기

- **기본 테마:** 라이트, 흑백. 테마는 배경·카드·강조·보조 강조·글자 다섯 가지 색입니다.
- **사진으로 테마 만들기:** 사진에서 색을 뽑아 어디에 어떤 색이 쓰일지 미리 보여 줍니다.
  - 마음에 안 들면 다른 조합 5개 중 고르거나, 스포이드로 사진을 찍어 원하는 자리에 넣습니다.
  - 색이 한 가지뿐인 사진은 전부 그 색으로 만듭니다.
- **글자색:** 기본은 자동(배경에서 가장 잘 보이는 색)이고 직접 고를 수도 있습니다. 대비가 낮으면 알려 주기만 하고 막지 않습니다.
- **글꼴:** 폰의 글꼴 파일(.ttf, .otf, .woff2)을 넣어 앱 전체에 씁니다. 파일이 커서 내보내기에는 포함하지 않습니다.
- **대상 사진:** 대상마다 사진을 넣으면 분류·세부·응원법 화면 위쪽과 내역 아이콘에 쓰입니다. 사진은 색을 바꾸지 않고, 화면 색은 언제나 앱 테마를 따릅니다.
- 대상 색과 분류 색은 통계와 내역 표시에만 쓰입니다.
- 폰의 시스템 글자 크기를 따릅니다.

## 저장과 내보내기

- 크롬에 영구 저장을 요청합니다.
- 설정에서 모든 데이터를 JSON 파일 하나로 내보내고 불러옵니다(덮어쓰기 전에 확인).
- 내보낸 파일 없이 앱 데이터를 지우면 복구할 수 없습니다.
- 지출 기록과 가사는 이 저장소에 올리지 않습니다.

## 제작 순서

1. **PWA:** 만들어서 GitHub Pages에 올리고 크롬으로 설치합니다.
2. **안드로이드 앱:** 같은 화면을 앱으로 감싸 위젯과 구글 드라이브 백업을 붙이고, APK를 GitHub에서 받아 설치합니다. 데이터는 내보내기·불러오기로 옮깁니다.

앱에서 꼭 확인할 것: 사진 테마(어두운 사진, 흑백 사진, 한 가지 색 사진, 고화질 사진 처리 속도), 정기 결제 알림.
