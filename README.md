# 내가 좋아하는 것들

좋아하는 것에 쓴 돈을 기록하고, 응원법을 모아서 외우는 앱입니다.

- 삼성 갤럭시와 크롬 기준의 PWA
- 로그인과 서버 없이 모든 데이터를 폰에만 저장
- 설치 후 오프라인으로 작동
- 특정 가수나 팬덤을 가정하지 않으며, 앱에 실제 이름을 미리 넣지 않음
- Play 스토어에는 올리지 않음

> 현재 상태: 명세 정리 단계이며 앱 코드는 아직 없습니다.

## 범위

**1단계에 포함:** 튜토리얼, 지출 기록, 내역, 통계, 응원법, 연말 결산, 설정, 내보내기와 불러오기

**1단계에서 제외:** 위젯, 구글 계정 연동, 카드 내역 대조, 결제 내역 자동 가져오기, 가사 크롤링, 아이폰 지원, Play 스토어 등록

## 화면 구성

하단 탭은 `기록`, `내역`, `통계`, `응원법`, `설정`이고, 연말 결산은 `통계` 안에 둡니다.

## 처음 설치와 튜토리얼

- 처음 설치하면 대상, 분류, 세부 버튼에 모두 `기타`만 있습니다.
- 처음 실행할 때만 게임 튜토리얼처럼 앱 사용법을 안내합니다. 목록 추가, 기록 입력, 내역 수정, 통계, 응원법을 차례로 보여 줍니다.
- 튜토리얼은 입력하는 방법만 설명하며, 무엇을 어느 분류에 넣어야 하는지 같은 기록 기준은 제시하지 않습니다.
- 예시는 `가수 A`, `행사 > 콘서트`처럼 화면 조작을 보여 주기 위한 간단한 이름만 씁니다.
- 튜토리얼의 예시는 실제 데이터에 저장하지 않고, 튜토리얼이 끝나면 사라집니다.
- 모든 단계에 `건너뛰기` 버튼이 있어 언제든 튜토리얼을 끝낼 수 있습니다.
- 설정에서 `튜토리얼 다시 보기`를 할 수 있습니다.

## 목록 관리

목록은 대상, 분류, 분류마다의 세부 버튼 세 단계입니다. 대상 목록은 지출과 응원법이 함께 씁니다. 무엇을 어떻게 나눌지는 사용자가 자유롭게 정하며, 앱은 기록 기준을 강제하지 않습니다.

- 모든 목록에 `기타`가 있으며 삭제할 수 없습니다. 각 분류의 세부 버튼에도 `기타`가 있습니다.
- 기록 화면과 응원법 화면의 목록 끝에 `+` 버튼을 두어 바로 추가합니다. 추가한 항목은 바로 선택됩니다.
- 앞뒤 공백을 제외하고 같은 이름은 새로 만들지 않고 기존 항목을 선택합니다.
- 이름을 바꾸면 지난 기록에도 반영합니다.
- 모든 목록은 길게 눌러 끌어서 순서를 자유롭게 바꿉니다.

## 지출 기록

`대상` → `분류` → `세부 버튼` → `금액` → 저장

- 세부 버튼을 건너뛰면 그 분류의 `기타`로 저장합니다.
- `기타`를 고르면 내용 칸이 나타납니다. 입력은 선택입니다.
- 금액은 원 단위 정수입니다.
- 날짜는 오늘로 자동 입력되고 과거와 미래로 바꿀 수 있습니다.
- 할부를 한 번에 기록할지 나눠서 기록할지, 재료를 따로 기록할지 묶어서 기록할지 같은 방식은 사용자가 정합니다.
- 메모는 평소에 접어 두며 입력은 선택입니다.
- 미래 날짜 기록은 `예정`으로 표시하고 해당 달의 지출과 결산에 포함합니다.

## 내역과 환불

- 기록은 최신순으로 표시하고 대상별로 걸러 봅니다.
- 기록을 눌러 날짜, 대상, 분류, 세부, 금액, 기타 내용, 메모, 환불 금액을 수정합니다.
- 환불 금액의 기본값은 0원이고 결제 금액보다 클 수 없습니다. 돌려받은 이유와 상관없이 돌려받은 금액을 입력합니다.
- 집계 금액은 `결제 금액 - 환불 금액`이며 결제한 달에 반영합니다.
- 전액 환불한 기록도 내역에 남습니다.

## 삭제

기록 한 건을 지울 때는 확인 없이 지우고 잠깐 `되돌리기`를 보여 줍니다. 그 밖의 삭제는 모두 지워지거나 옮겨지는 범위와 건수를 보여 준 뒤 정말 지울지 묻습니다. 삭제한 항목은 되살리지 않습니다.

| 삭제 | 결과 |
|---|---|
| 대상 삭제 | 그 대상의 지출 기록과 응원법을 모두 삭제 |
| 분류 삭제 | 모든 대상에서 그 분류와 세부 버튼을 삭제하고, 기록은 분류 `기타`의 세부 `기타`로 이동 |
| 세부 삭제 | 그 세부 버튼을 삭제하고, 모든 대상의 기록은 같은 분류의 세부 `기타`로 이동 |
| 데이터만 삭제 | 대상, 분류, 세부 화면에서 항목은 남기고 그 안의 지출 기록만 삭제 |

- 대상의 `데이터만 삭제`는 지출 기록만 지우며 응원법은 남깁니다.
- 삭제로 `기타`에 옮긴 기록은 기타 내용 칸에 이전 이름을 자동으로 넣습니다. 분류 삭제는 `행사 > 콘서트`, 세부 삭제는 `콘서트` 형식입니다.
- 기타 내용 칸에 이미 글이 있으면 이전 이름을 앞에 붙이고 기존 글은 유지합니다.

## 옮기기

- 기록 한 건: 기록을 눌러 대상, 분류, 세부를 바꿉니다.
- 여러 건: 내역에서 기록을 여러 개 골라 한 번에 옮깁니다.
- 세부 버튼 이동: 세부 버튼을 다른 분류로 옮기면 그 기록도 함께 옮겨집니다.
- 세부를 분류로 꺼내기: 세부 버튼을 새 분류로 만들고 그 기록을 새 분류의 세부 `기타`로 옮깁니다.

## 통계

모든 금액은 집계 금액 기준이며, 기간은 `월`과 `연` 중에서 고릅니다. 기본은 이번 달입니다.

- 기간 내 1위 대상과 1위 분류
- 대상 랭킹
- 분류 랭킹
- 대상별 분류 금액과 세부 금액
- 연간 대상별 금액

## 응원법

- 대상별, 곡별로 저장하고 곡 제목으로 검색합니다.
- 곡 하나는 대상 하나에만 저장합니다.
- 곡마다 원본 가사 하나와 응원법 층 하나를 따로 저장합니다.
- 가사는 붙여넣기로 입력합니다. 앱에 가사를 미리 넣거나 크롤링하지 않습니다.
- 공유 메뉴로 가사를 넣는 기능은 지원 여부를 확인한 뒤 추가합니다.
- 원본은 잠가 두고 `가사 수정`에서만 고칩니다. 고친 부분의 응원법은 다시 표시해야 할 수 있습니다.
- 응원법을 초기화해도 원본은 유지합니다.
- **떼창:** 원본 가사의 일부를 선택해 색을 지정합니다.
- **추가 응원:** 가사에 없는 구호를 줄 사이나 줄 안의 원하는 위치에 넣고 색을 지정합니다.
- 색은 기본 4가지로 시작합니다.
- 곡마다 링크를 여러 개 저장합니다.
- 공연장 보기는 큰 글자와 어두운 화면을 제공하고, 지원되는 브라우저에서는 보는 동안 화면이 꺼지지 않게 합니다.

| 보기 모드 | 떼창 | 추가 응원 |
|---|---|---|
| 응원법 보기 | 색으로 강조 | 색으로 강조해서 표시 |
| 원본 가사 | 일반 가사 | 숨김 |
| 외우기 | 칸으로 가림 | 칸으로 가림 |

- 외우기 모드에서 칸을 누르면 열리고 다시 누르면 닫힙니다. `모두 보기`와 `모두 가리기` 버튼을 둡니다.
- 마지막에 쓴 보기 모드를 기억합니다.
- 곡 상세를 열면 펼친 횟수를 1회 세고, 같은 곡을 30분 안에 다시 열면 세지 않습니다.

## 연말 결산 카드

카드 6장으로 구성합니다.

1. 올해 총액
2. 돈을 많이 쓴 달 TOP 3
3. 많이 쓴 대상 TOP 3
4. 많이 쓴 분류 TOP 3
5. 응원법을 많이 펼친 달 TOP 3
6. 많이 펼친 곡 TOP 3

- 새해에 처음 앱을 열면 지난해 결산을 자동으로 한 번 보여 줍니다. 1월 1일이 아니어도 그해 첫 실행이면 보여 줍니다.
- 카드는 옆으로 넘어가는 애니메이션이 있고, 손가락으로 밀어서 넘길 수 있습니다.
- `통계`에서 언제든 다시 볼 수 있고 연도를 바꿔 지난 결산도 볼 수 있습니다.
- 결산 이미지는 폰의 공유 창으로 갤러리에 저장하거나 보낼 수 있습니다.
- 연도 기준은 1월 1일부터 12월 31일까지이며 폰의 시간을 따릅니다.
- 3개가 안 되면 있는 만큼만 표시하고, 공동 순위는 같은 순위로 표시합니다.
- 데이터가 없는 카드는 건너뜁니다.

## 저장, 내보내기, 업데이트

- 크롬이 저장 공간 부족으로 앱 데이터를 지우지 않도록 영구 저장을 요청합니다.
- 설정에서 모든 데이터를 JSON 파일 하나로 내보내고 불러옵니다. 불러올 때는 덮어쓰기 전에 확인을 받습니다.
- 백업 알림은 넣지 않습니다.
- 앱이나 브라우저 데이터를 지웠을 때 내보낸 파일이 없으면 복구할 수 없습니다.
- 새 버전을 올리면 다음에 앱을 열 때 자동으로 바뀌며 기록은 유지됩니다.
- 지출 기록과 가사는 이 저장소에 올리지 않습니다.

## 제작 순서

1. **PWA:** 화면과 기능을 만들고 폰 화면 크기로 테스트한 뒤 GitHub Pages에 올려 크롬으로 설치합니다.
2. **안드로이드 앱:** 같은 화면을 안드로이드 앱으로 감싸고 위젯과 구글 계정 연동을 붙입니다. 설치 파일(APK)은 GitHub에 올려 직접 설치합니다. 이 단계에는 Android Studio가 필요합니다.

- PWA의 데이터는 내보내기와 불러오기로 안드로이드 앱에 옮깁니다.
- 구글 계정 연동은 설정의 메뉴 하나로 켜고 끄며, 켜면 구글 드라이브의 앱 전용 숨김 폴더에 데이터를 백업합니다.
- 위젯 확장을 위해 저장 부분을 분리하고 기록 저장 로직을 하나로 묶습니다. 위젯의 입력 순서는 앱과 같고, 목록 관리는 앱에서 합니다.
